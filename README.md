## 3. 個人程式作品 - 遊戲設計——推箱子

**使用語言：** C++、Qt

**成果：** [遊戲功能展示影片](https://www.youtube.com/watch?v=GkovijjWddk)

**簡介：**
引用 Qt 的 class，包括 menu 頁面按鈕的配置、匯入地圖的佈局以及滑鼠、鍵盤事件。遊戲方式為移動角色將所有箱子推向儲存點即為勝利，並額外增加一些互動，如：撿金幣、採炸彈等，讓遊戲增加豐富度。
